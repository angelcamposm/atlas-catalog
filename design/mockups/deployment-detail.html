About

Deployment record created by the CI webhook from the deploy-production workflow run. The catalog stores the immutable snapshot of the deployment: which component, which release, which environment, which cluster, which commit, and which image digest. It does not manage replicas, strategy, namespace or service account — those are owned by the workload definition (Helm chart / kustomize / Argo) referenced by the workflow.
