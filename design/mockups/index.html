CRUD drawers (Create / Edit)

Each list has a side drawer (push on wide screens, overlay on standard). Click + New or the row's edit button to open it.

api APIs — Create / EditIdentity, interface, lifecycle fields. widgets Components — Create / EditSource, language, lifecycle and tier. database Resources — Create / EditType, connection, provenance, compliance. link Links — Create / EditTitle, URL, type and linked entity. hub Systems — Create / EditDomain, tier, architecture and ownership. domain Domains — Create / EditTop-level business area. extension Capabilities — Create / EditBusiness outcome, maturity, supporting systems. table Entities — Create / EditDomain, owning system and schema attributes. lan Clusters — Create / EditType, region, capacity and connection. dns Nodes — Create / EditCluster, role, capacity and taints. cached Environments — Create / EditType, clusters and approval policy. rocket_launch Deployments — Create / EditComponent, release, cluster and rollout strategy. new_releases Releases — Create / EditVersion, changelog and promotion rules. account_tree Workflows — Create / EditTriggers, pipeline YAML and notifications. memory CI Servers — Create / EditType, URL, API token and ownership. groups Groups — Create / EditName, type, email, icon, label, parent. person Users — CreateName, email, password. Role/groups come from relations. manage_accounts Service accounts — CreateName, description, owner, metadata, is_enabled. key Credentials — CreateName, type, owner, username, secret (write-only). verified Compliance requirements — CreateName, standard, controls (JSON), is_enabled.

Security & webhooks

Service accounts hold tokens, credentials hold the secret material that tokens reference, and webhooks let CI servers push events into the catalog.
