Webhooks

External systems push events to the catalog. The catalog uses them to ingest CI runs and deployments.
rocket_launch
Deployment events
POST /api/v1/webhooks/deployments

Called by CI servers after a deployment finishes. Creates or updates a Deployment record with the immutable snapshot (component, release, environment, cluster, commit, image digest, status). 

$ curl -X POST {catalog}/api/v1/webhooks/deployments \
    -H "Authorization: Bearer cat_pat_..." \
    -H "X-Webhook-Signature: sha256=..." \
    -d '{
      "component": "payments-service",
      "environment": "production",
      "cluster": "prod-eu-west-1",
      "release": "v2.14.0",
      "version": "v2.14.0",
      "commit_hash": "a3f9c21",
      "docker_image_digest": "sha256:9f8e7d...",
      "workflow_run_id": 1284,
      "triggered_by": "m.ramos",
      "status": "success",
      "started_at": "2026-06-14T06:42:11Z",
      "ended_at": "2026-06-14T06:45:59Z",
      "duration_milliseconds": 228000,
      "meta": { "replicas": 6, "namespace": "payments" }
    }'

Workflow run events
POST /api/v1/ci-cd/workflows/runs

Called by CI servers to register a new WorkflowRun (result, duration, started_at, commit). The catalog also stores a WorkflowRunCommit with the SHA, author, branch and message. 

$ curl -X POST {catalog}/api/v1/ci-cd/workflows/runs \
    -H "Authorization: Bearer cat_pat_..." \
    -d '{
      "workflow_job_id": 7,
      "display_name": "Deploy payments-service to production",
      "description": "Promote the v2.14.0 build",
      "result": "SUCCESS",
      "duration_milliseconds": 228000,
      "started_at": "2026-06-14T06:42:11Z",
      "started_by": "m.ramos",
      "url": "https://github.com/.../runs/1284",
      "is_enabled": true,
      "commit": {
        "sha": "a3f9c21",
        "message": "feat(payments): idempotent payouts",
        "author_name": "Marta R.",
        "author_email": "marta.r@acme.dev",
        "branch": "main",
        "committed_at": "2026-06-14T06:24:00Z"
      }
    }'

CI server sync
POST /api/v1/ci-cd/servers/{id}/sync

Triggers a re-sync of a CI server: re-reads the list of workflow jobs, updates last_synced_at, refreshes the counts on the server detail page. 

$ curl -X POST {catalog}/api/v1/ci-cd/servers/1/sync \
    -H "Authorization: Bearer cat_pat_..."

# Response: 202 Accepted
# { "queued_at": "2026-06-14T06:42:11Z" }
